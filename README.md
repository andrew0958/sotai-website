# Sotai Biosystems Website

Static company website for Sotai Biosystems, prepared for NVIDIA Inception / startup application review.

Primary website: https://sotaibiosystems.com.tw/

## Files

- `index.html` - homepage content
- `styles.css` - responsive design
- `script.js` - small header scroll behavior
- `assets/` - copied Sotai visual assets

## Local preview

Open `index.html` directly in a browser.

## Deployment options

This is a static site and can be uploaded to:

- GitHub Pages
- Netlify
- Vercel
- Any standard web hosting service

## Before NVIDIA Inception submission

Confirm these items:

- Functional public URL
- One business executive contact
- One different developer contact
- Company incorporation details
- Direct non-generic email addresses for both contacts
